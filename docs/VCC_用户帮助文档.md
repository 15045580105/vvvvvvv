# VCC 车载测试平台 用户帮助文档

**版本：v1.0**

---

## 一、软件概述

VCC（Vehicle Communication & Configuration）车载测试平台是一款面向汽车电子控制单元（ECU）的综合诊断测试工具。软件基于 UDS（ISO 14229）、DoIP（ISO 13400）、SomeIP 等车载网络协议，提供设备管理、故障诊断、数据读写、固件升级、文件传输等核心功能，适用于 ECU 开发、集成测试及产线诊断等场景。

### 系统要求

- **操作系统**：Windows 10/11（64 位）
- **网络接口**：以太网口（用于 DoIP / SomeIP 通信）
- **运行环境**：已打包为独立安装程序，无需额外安装 Python 环境

### 启动与激活

1. 双击桌面快捷方式或运行 `VCC_Setup_1.0.0.exe` 安装后启动
2. 首次启动将弹出 **激活窗口**，需输入激活码完成授权
3. 授权到期前 15 分钟软件将弹窗提醒，到期后应用自动锁定，需重新激活

> **注意**：软件采用单实例模式，同一台电脑仅允许运行一个 VCC 实例。

## 三、功能模块详解

### 3.1 📁 设备管理

设备管理是 VCC 的核心基础模块，负责 ECU 设备的添加、编辑、删除和多协议连接管理。

#### 操作步骤

1. 点击左侧导航树「设备管理」打开页签
2. 在页面左侧表单填写设备信息（设备名、类型、DoIP/SomeIP/SSH 配置）
3. 点击「添加设备」按钮，设备出现在右侧列表
4. 选中设备 → 点击工具栏 DoIP 按钮连接 → 状态变为 🟢 在线
5. 再点击 SSH 按钮连接 SSH（依赖 DoIP 已连接）
6. 点击 SomeIP 按钮连接 SomeIP

#### 添加设备

在设备管理页面左侧填写设备信息：

| 字段 | 说明 | 默认值 |
|------|------|--------|
| 设备名 | 自定义名称（必填） | — |
| 设备类型 | ECU / 网关 / 域控 / 其他 | ECU |
| **DoIP 配置** | | |
| DoIP IP | 设备 DoIP 地址 | — |
| DoIP 端口 | DoIP 端口号 | 13400 |
| **SomeIP 配置** | | |
| SomeIP IP | SomeIP 通信地址 | — |
| 标准组播 IP | SomeIP SD 组播地址 | 239.71.0.2 |
| 标准组播端口 | SomeIP SD 端口 | 30490 |
| VLAN ID | VLAN 标识 | 4 |
| 客户端端口 | SomeIP 客户端端口 | 30813 |
| 客户端 ID | SomeIP 客户端 ID | 30813 |
| **SSH 配置** | | |
| SSH IP | SSH 登录地址 | — |
| SSH 端口 | SSH 端口号 | 22 |
| 用户名 | SSH 用户名 | — |
| 密码 | SSH 密码 | — |

点击 **添加设备** 按钮将设备加入列表。

#### 注意事项

> ⚠️ **注意**：连接顺序：必须先连接 DoIP，再连接 SSH。

> 💡 **提示**：每个协议同时只允许一个设备连接。

> 💡 **提示**：删除设备前必须断开所有协议连接，否则无法删除。

> 💡 **提示**：连接超时 15 秒自动取消，避免 UI 卡死。

> 💡 **提示**：编辑设备时可点击 ⚙ 按钮进入高级设置（DoIP/诊断层/SomeIP 参数）。

#### 连接状态颜色标识

- 连接状态在设备表格中以颜色标识：
  - 🟢 **在线/建链成功** — 协议已连接
  - 🔴 **已断开/未连接** — 协议未连接
  - 🟡 **连接中** — 正在建立连接

#### 编辑与删除

- **编辑**：选中设备后点击编辑按钮，弹出编辑对话框修改设备信息
- **删除**：仅在设备所有协议均为离线/断开状态时允许删除，需二次确认

#### 高级配置

编辑设备时可点击 **⚙** 按钮进入高级设置：
- **DoIP 设置**：网络接口选择、连接超时等
- **诊断层设置**：S3 客户端定时器、P2 超时等 UDS 参数
- **SomeIP 设置**：SomeIP 协议高级参数

#### 快捷操作

| 工具栏按钮 | 功能 |
|-----------|------|
| DoIP | 连接/断开 DoIP |
| SSH | 连接/断开 SSH |
| SomeIP | 连接/断开 SomeIP |
| ✏️ | 编辑设备信息 |
| 🗑️ | 删除设备 |
| 🚗 | 跳转到设备升级页面 |
| 🔍 | 跳转到拓扑监控页面 |

### 3.3 ⚙️ 性能监控

性能监控页面通过 SSH 协议实时采集 ECU 的系统性能数据：

- **CPU 使用率**：实时监控处理器负载
- **内存使用率**：RAM 占用情况
- **磁盘 I/O**：磁盘读写状态

#### 操作步骤

1. 确保目标设备 SSH 已连接
2. 点击左侧「性能监控」打开页签
3. 点击开始采集，实时查看 CPU/内存/磁盘/进程数据
4. 支持导出数据文件供离线分析

#### 注意事项

> 💡 **提示**：仅依赖 SSH 连接，无需 DoIP。

> ⚠️ **注意**：采集频率会影响 ECU 性能，建议合理设置采集间隔。

#### 注意事项

### 3.5 ⚠️ DTC 故障诊断

DTC（Diagnostic Trouble Code）故障诊断模块用于读取、分析和管理 ECU 故障码。

#### 操作步骤

1. 确保设备 DoIP 已连接
2. 点击「读取故障码」按钮
3. 查看故障码列表，通过 Tab 切换全部/当前/历史/未决分类
4. 选中某个故障码 → 点击「读取冻结帧」查看详细数据
5. 点击「清除故障码」清空所有故障
6. 使用搜索框按 DTC 编码或描述过滤
7. 点击表头可按升序/降序/默认三态排序

#### 故障分类

读取结果按状态自动分类：

| 分类 | 说明 |
|------|------|
| 全部故障 | 所有故障码 |
| 当前故障 | Status Bit 0 = 1，当前正在发生的故障 |
| 历史故障 | Status Bit 3 = 1，已确认的历史故障 |
| 未决故障 | Status Bit 2 = 1，尚未确认的间歇性故障 |

#### 故障码信息

每个故障码显示：
- **DTC 编码**：如 `P31AE87`（遵循 ISO 15031-6 格式）
- **故障描述**：从 DPT 数据库自动匹配中文描述
- **子系统**：故障所属子系统
- **状态码**：原始十六进制状态字节

#### 注意事项

> ⚠️ **注意**：需要加载 DPT 文件才能显示中文故障描述。

> 💡 **提示**：Status Bit 含义：Bit0=当前故障、Bit2=未决故障、Bit3=历史故障。

> 💡 **提示**：故障码列表自动保存，重启软件后恢复。

> 💡 **提示**：冻结帧解析依赖 DPT 配置。

### 3.6 🔍 DID 数据管理

DID（Data Identifier）数据管理模块用于读取和写入 ECU 数据标识符。

#### 操作步骤

1. 确保 DoIP 已连接
2. 在 DID 输入框中输入地址（如 `F190` 或 `22F190`）
3. 点击读取按钮查看结果
4. 写入 DID：输入数据 → 点击写入 → 自动执行安全访问流程（Seed & Key）
5. 加载 DPT 文件后自动解析原始数据为可读字段
6. 支持数据持久化和历史记录

#### 注意事项

> ⚠️ **注意**：写入操作会自动触发安全访问（Seed & Key），需确保 ECU 支持。

> 💡 **提示**：需要 DPT 文件才能解析 DID 数据含义。

> 💡 **提示**：支持批量读取多个 DID 地址。

### 3.7 🧪 UDS 指令编排

UDS 指令编排模块允许用户自定义 UDS 诊断指令序列并批量执行。

#### 操作步骤

1. 在指令表格逐行添加 UDS 请求（Hex 格式）
2. 设置指令名称、请求报文、期望响应
3. 可插入延时指令（⏱，单位毫秒）
4. 勾选/取消勾选控制是否执行该行
5. 设置循环次数，选择是否「失败时停止」
6. 点击执行，逐条发送并记录响应
7. 支持导入/导出 JSON 配置文件

#### 注意事项

> ⚠️ **注意**：请求报文必须为合法 Hex 格式。

> 💡 **提示**：建议先用单条指令测试连通性再批量执行。

> 💡 **提示**：前提条件：DoIP 已连接。

#### 注意事项

> 💡 **提示**：大文件传输时请保持网络稳定，避免传输中断。

### 3.10 📡 总线数据下载

总线数据下载模块用于从 ECU 下载总线通信数据（如 CAN 报文记录等），通过 SSH 通道进行文件传输。

> 💡 **提示**：依赖 SSH 连接（SSH 依赖 DoIP 先连接）。

### 3.11 🚗 设备升级

设备升级模块支持 ECU 固件的在线刷写（OTA），遵循 UDS 刷写流程。

#### 操作步骤（常规升级）

1. 确保 DoIP 已连接
2. 点击浏览按钮选择升级包文件（.zip / .bin），支持拖拽文件
3. 加载对应的 JSON 升级配置文件
4. 点击「开始升级」
5. 系统自动执行完整刷写流程（见刷写流程图）
6. 等待升级完成，ECU 自动复位

#### 刷写流程（自动执行）

```
等待 ECU 就绪
→ 读取 DID（F17F/F180/F187/F189）版本校验
→ 进入默认会话 (10 01)
→ 进入扩展会话 (10 03)
→ 安全访问 (27 21/22)
→ 检查下载预条件 (31 01 21 01)
→ 请求下载 (38 01)
→ 传输数据 (36, 分块传输)
→ 传输结束 (37)
→ 校验文件 (31 01 21 02, SHA256)
→ 擦除/合并 (31 01 21 05)
→ 重新认证
→ 安装 (31 01 21 03)
→ 轮询安装进度 (22 21 04)
→ ECU 复位 (11 01)
```

#### 压测模式

配置多组「升级包+配置文件」任务 → 设置循环次数 → 自动重复升级，每轮自动处理 ECU 复位和重连。

#### 注意事项

> ⚠️ **注意**：升级期间其他模块的 DoIP 请求会被自动拦截（升级屏障），升级完成后自动解除。

> ⚠️ **注意**：升级过程中不可中断，请保持网络稳定，勿关闭软件。

> 💡 **提示**：必须同时提供升级包和 JSON 配置文件。

> 💡 **提示**：支持 TesterPresent (3E) 心跳自动管理，防止会话超时。

### 3.12 📝 日志配置

日志配置模块用于管理 ECU 和应用的日志等级配置，分为三个功能区：

#### ECU 日志配置步骤

1. 确保 DoIP 已连接
2. 从下拉列表选择目标 ECU（支持多选）
3. 选择日志等级（DEBUG/INFO/WARN/ERROR）
4. 点击「执行」→ 系统通过 UDS DID 写入方式下发到 ECU
5. 执行完成后自动回读并刷新 ECU 状态表格，确认配置生效

#### 应用日志配置（CCUA）步骤

1. 确保 SSH 已连接
2. 从 ECU 读取应用日志配置列表
3. 按 ECU ID / APP ID / 日志等级筛选，支持分页浏览
4. 修改单个或批量修改 CCUA 应用日志等级
5. 系统弹窗询问是否重启 CCU

#### 导入配置文件

点击「导入映射文件」按钮，选择 `process_log_config_map.json` 文件。

#### 恢复默认配置

支持恢复 CCUA/CCU0/CCU1 默认配置，可删除 `/log` 目录下 DLT 日志文件。

#### 注意事项

> ⚠️ **注意**：ECU 日志配置依赖 DoIP，应用日志配置和恢复操作依赖 SSH。

> 💡 **提示**：修改 CCUA 应用日志后需重启 CCU 才能生效。

> ⚠️ **注意**：恢复默认配置会删除 /log 目录下所有 DLT 日志文件。

> 💡 **提示**：恢复 CCUA 配置后可自动触发 CCU 重启并等待重连（最长 120 秒）。

### 3.13 🔧 常用配置

常用配置模块提供软件全局诊断参数和协议配置，分为多个子页面：

#### 操作步骤

1. 打开常用配置页面
2. **DoIP 设置**：选择本机网卡（多网卡时必须选对）、配置连接超时参数
3. **诊断层参数**：设置 S3 客户端定时器（影响 3E 发送频率）、P2/P2* 超时
4. **服务配置导入**：导入 JSON 配置文件，加载 2E/31 服务定义，支持分页浏览
5. **SomeIP 配置**：SomeIP 协议相关参数设置

#### 注意事项

> ⚠️ **注意**：多网卡环境下必须选择正确的网卡，否则 DoIP 无法连通。

> 💡 **提示**：S3 定时器影响 TesterPresent (3E) 发送频率，设置不当会导致会话超时。

> 💡 **提示**：当系统检测到本机网络接口与 ECU 不在同一网段时，会在操作日志中提示并提供跳转链接。

### 3.15 🌐 报文解析界面

报文解析界面用于解析 SomeIP 报文内容：

#### 操作步骤

1. 加载报文文件（支持拖拽文件到界面）
2. 自动解析 SomeIP 消息头和载荷

4. 实时展示解析结果

#### 注意事项

> 💡 **提示**：报文解析界面为离线分析工具，无需连接即可使用。

> 💡 **提示**：需要 DPT 文件才能完整解析载荷含义。

## 四、DPT 配置管理

DPT（Diagnostic Parameter Table）是诊断参数表，VCC 通过加载 DPT 文件实现：

- **DTC 故障描述**：自动匹配故障码中文含义
- **DID 数据解析**：按定义解析 DID 原始数据为可读字段
- **冻结帧解析**：解析冻结帧中的 DID 数据

### 加载 DPT

- 软件启动时自动加载上次使用的 DPT 文件
- 加载结果以 Toast 提示显示（成功/失败）
- 可在 **常用配置** 中重新选择 DPT 文件

## 九、常见问题（FAQ）

### Q1：连接 DoIP 失败怎么办？

1. 检查网线是否插好，本机与 ECU 是否在同一网段
2. 进入 **常用配置 > DoIP 设置**，确认已选择正确的网络接口
3. 查看操作日志中的错误信息

### Q2：SSH 连接提示"请先连接 DoIP"？

SSH 依赖 DoIP 通道，请先确保 DoIP 连接成功（状态显示"建链成功/在线"），再连接 SSH。

### Q3：升级过程中其他功能无法使用？

这是正常现象。升级期间系统会激活"升级屏障"，自动拦截其他模块的 DoIP 诊断请求，防止干扰刷写流程。升级完成后自动解除。

### Q4：DTC/DID 页面提示"DPT 解析未完成"？

需要加载 DPT 配置文件。进入 **常用配置** 选择正确的 DPT Excel 文件。

### Q5：软件启动时显示"授权已过期"？

请重新生成激活码并在弹出的激活窗口中输入，完成重新激活后即可继续使用。

### Q6：连接超时怎么办？

系统设置了 15 秒连接超时保护。超时后会自动取消连接并重置状态，您可以检查网络后重新连接。

### Q7：日志配置修改后为什么没有生效？

日志配置修改通过 SSH 写入 ECU 配置文件，修改后需要重启 CCU 才能生效。系统会弹窗询问是否立即重启，如选择不重启，请择机手动重启设备。

### Q8：文件传输/日志下载提示"设备未连接"？

文件传输和日志下载依赖 SSH 通道。请先确保设备 DoIP 和 SSH 均已连接成功。

### Q9：升级时提示"配置文件未找到"？

常规升级需要同时指定升级包文件和 JSON 配置文件。请确保配置文件路径正确且文件存在。配置文件应包含 package 信息、远程路径、分块大小等参数。

### Q10：如何查看软件授权信息？

进入 **配置中心 > 常用配置**，可查看当前授权状态、激活码和到期时间。

## 十一、配置文件说明

| 配置文件/目录 | 位置 | 说明 |
|-------------|------|------|
| 设备列表 | AppData/device_config.json | 保存已添加的设备信息和连接参数 |
